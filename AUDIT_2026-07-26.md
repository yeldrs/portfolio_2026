## CLAUDE.md

### Écart 1 — `validate-frontmatter.cjs` toujours listé comme dette
- **Écart** : arborescence + "Known, tracked debt" décrivent `validate-frontmatter.cjs` comme script orphelin dépendant de `gray-matter` (absent de `package.json`) — vs le fichier a été supprimé le 2026-07-11.
- **Catégorie** : dette déjà résolue mais encore listée.
- **Fichier(s) vérifié(s)** : `Glob validate-frontmatter.cjs` (aucun résultat), `MAINTENANCE_LOG.md`.
- **Impact** : un agent pourrait chercher à nettoyer/supprimer un fichier inexistant.
- **Correction proposée** : retirer la ligne d'arborescence (l.71) et le bullet de dette (l.123).

### Écart 2 — règle `html,body` de `global.css` toujours listée comme dette
- **Écart** : "Known, tracked debt" affirme que cette règle référence des variables CSS non définies — vs elle a été supprimée le 2026-07-11 (remplacée par un commentaire expliquant que le fond vient des classes de `BaseLayout`).
- **Catégorie** : dette déjà résolue mais encore listée.
- **Fichier(s) vérifié(s)** : `src/styles/global.css`, `MAINTENANCE_LOG.md`.
- **Impact** : un agent croirait ce point encore ouvert, risque de correctif inutile.
- **Correction proposée** : retirer ce bullet (l.121).

### Écart 3 — `repomix-output.xml` présenté comme "à gitignorer"
- **Écart** : "Known, tracked debt" dit que `repomix-output.xml` est versionné et devrait être gitignoré — vs il est déjà dans `.gitignore` et untracké.
- **Catégorie** : dette déjà résolue mais encore listée / obsolète.
- **Fichier(s) vérifié(s)** : `.gitignore`, `git ls-files repomix-output.xml`, `git check-ignore -v`.
- **Impact** : masque la vraie dette actuelle (voir repomix Écart 1 ci-dessous).
- **Correction proposée** : remplacer ce bullet par : le pattern `"Whitepaper*.txt"` dans `repomix.config.json` ne matche pas `whitepaper.txt` (casse) → le whitepaper entier est toujours embarqué dans le snapshot.

### Écart 4 — images manquantes de `biomimicry.md` non signalées
- **Écart** : rien dans CLAUDE.md ne signale que `biomimicry.md` référence des `projectImages` (`/images/biomimicry/*`) inexistantes sur disque.
- **Catégorie** : dette réelle non documentée (spécifique à CLAUDE.md).
- **Fichier(s) vérifié(s)** : `Glob public/images/biomimicry/*` (aucun résultat), `src/content/projects/biomimicry.md`.
- **Impact** : CLAUDE.md est lu en priorité par un agent ; suivre "passer `isDraft: false`" sans lire aussi le whitepaper casserait le build.
- **Correction proposée** : ajouter au bloc dette : "biomimicry.md's projectImages reference `/images/biomimicry/*` paths that don't exist on disk yet — do not flip `isDraft` to `false` until images are provided."

## Whitepaper (whitepaper.txt)

### Écart 1 — fan-out de `Container.astro` erroné
- **Écart** : §3.1 indique "8 fichiers" importeurs — vs réel = 7 (`Footer.astro`, `Hero.astro`, `Navbar.astro`, `404.astro`, `about.astro`, `index.astro`, `work/[slug].astro`).
- **Catégorie** : obsolète.
- **Fichier(s) vérifié(s)** : grep `import.*Container` sur `src/**`.
- **Impact** : fausse l'évaluation du rayon d'impact avant modification d'un composant partagé (demandé par CLAUDE.md workflow point 4).
- **Correction proposée** : "8 fichiers" → "7 fichiers" en §3.1.

### Écart 2 — fan-out de `Button.astro` erroné
- **Écart** : §3.1 indique "4 fichiers" importeurs — vs réel = 2 (`about.astro`, `ProjectCard.astro`).
- **Catégorie** : obsolète.
- **Fichier(s) vérifié(s)** : grep `import Button from` sur `src/**`.
- **Correction proposée** : "4 fichiers" → "2 fichiers" en §3.1.

### Écart 3 — radius `2xl` absent de la doc
- **Écart** : §4.2 liste `md (6px), xl (12px), card (12px)` — vs `tokens.js` définit aussi `primitives.borderRadius['2xl'] = "16px"`, consommé dans `tailwind.config.mjs`.
- **Catégorie** : manquant.
- **Fichier(s) vérifié(s)** : `src/styles/tokens.js`, `tailwind.config.mjs`.
- **Correction proposée** : ajouter `2xl (16px)` à la liste en §4.2.

### Écart 4 — mapping `projectImages` incomplet (contradiction avec CLAUDE.md)
- **Écart** : §5 ne documente que les index pairs (0, 2, 4, 6, 8+) sans jamais mentionner 1/3/5/7 — vs CLAUDE.md et le contenu réel (`900care.md`, `biomimicry.md`) montrent un pairing symétrique complet : 0/1=contexte, 2/3=rôle, 4/5=conception, 6/7=résultats, 8+=carrousel.
- **Catégorie** : **contradiction** whitepaper vs CLAUDE.md — CLAUDE.md est correct.
- **Fichier(s) vérifié(s)** : `src/content/config.ts`, `src/content/projects/900care.md` (commentaires `# Index 3: roleImage2 (Optional)` etc.), `src/content/projects/biomimicry.md`.
- **Impact** : le whitepaper qualifie lui-même ce mapping de "point fragile majeur" (§7.3) — une description incomplète est exactement le terrain où un agent placerait une image au mauvais index.
- **Correction proposée** : réécrire la liste d'index de §5 pour refléter le pairing complet ci-dessus.

### Écart 5 — token `fontSize.xs` orphelin
- **Écart** : `tokens.js` définit `primitives.fontSize.xs` (12px), mais `tailwind.config.mjs` ne le reprend pas dans son override `fontSize` (seuls sm→6xl sont redéfinis) → `text-xs` retombe sur la valeur par défaut Tailwind, pas sur le token. Non signalé par le whitepaper (§4.2) ni par CLAUDE.md.
- **Catégorie** : dette réelle non documentée.
- **Fichier(s) vérifié(s)** : `src/styles/tokens.js`, `tailwind.config.mjs`.
- **Impact** : violation silencieuse de la règle d'or "tokens-only".
- **Correction proposée** : ajouter une entrée en §7 (ou `MAINTENANCE_LOG.md`) : `fontSize.xs` défini dans `tokens.js` mais non consommé par `tailwind.config.mjs`.

### Écart 6 — commentaire trompeur dans `astro.config.mjs` (hors périmètre doc)
- **Écart** : l.12 commente "✅ 3. 'directory' format to create /about/index.html" alors que l.14 fixe `build.format: 'file'` (comportement réel = `/about.html`, correctement décrit par ailleurs dans whitepaper et CLAUDE.md).
- **Catégorie** : dette réelle non documentée (mineure, commentaire de code, pas une affirmation documentaire).
- **Fichier(s) vérifié(s)** : `astro.config.mjs` l.9-16.
- **Impact** : faible — comportement correct, seul le commentaire trompe.
- **Correction proposée** : aucune action sur les 3 documents ; signalé pour arbitrage éventuel sur le code lui-même.

- **Catégorie** : obsolète / bug de config.

- **Catégorie** : manquant.
